# ⛽ Fuel Reimbursement & Compensation System (ระบบรายงานสรุปค่าชดเชยน้ำมัน)

เว็บแอปพลิเคชันวิเคราะห์ สรุปรายงาน และคำนวณเงินชดเชยค่าน้ำมันตามระยะทางวิ่งจริง (เกณฑ์ DIFF. + 10%) และราคาน้ำมันดีเซลรายวัน ครอบคลุมทั้ง 18 สาขา และรองรับข้อมูลย้อนหลัง 8 เดือน (มีนาคม – ตุลาคม 2569)

---

## 🌟 ฟังก์ชันหลักของระบบ (Key Features)

1. **📊 แดชบอร์ดภาพรวมรายเดือน (Monthly Executive Dashboard)**
   - วิเคราะห์เปรียบเทียบแนวโน้มค่าชดเชยน้ำมันย้อนหลัง 8 เดือน (มี.ค. – ต.ค. 2569)
   - สรุปตัวเลขสะสมทั้งปี (YTD): ยอดเงินชดเชยสะสม, ระยะทางสุทธิ (กม.), ปริมาณน้ำมัน (ลิตร), ยอดส่งสินค้า (ถัง) และต้นทุนเฉลี่ยต่อถัง (บาท/ถัง)
   - กราฟเปรียบเทียบความสัมพันธ์ระหว่างยอดเงินชดเชยกับความผันผวนของราคาน้ำมันดีเซลรายวัน
   - **ระบบ Drill-down**: คลิกที่แถวเดือนใดในตาราง ระบบจะเปิดไปยังหน้ารายงานสรุปของเดือนนั้นทันที
   - **วิเคราะห์เปรียบเทียบแยก 18 สาขา**: ตารางเปรียบเทียบประสิทธิภาพ สัดส่วนงบประมาณ (% Share) และปุ่มซูมวิเคราะห์รายสาขา

2. **📋 รายงานสรุปค่าชดเชยประจำเดือน (Detailed Monthly Report)**
   - ดรอปดาวน์เลือกดูข้อมูลได้ครบทั้ง 8 เดือน (มี.ค. – ต.ค. 2569)
   - ตัวกรองแยก 18 สาขามาตรฐาน (10 บางพลี, 11 สุขุมวิท 50, ..., 98 ดอนเมือง)
   - **ตารางสรุปรายวัน**: รายละเอียดเลขไมล์, ปริมาณน้ำมัน, ราคาน้ำมันดีเซลรายวัน (สามารถแก้ไขราคาน้ำมันเพื่อจำลองคำนวณใหม่ได้ทันที), ยอดส่ง และค่าชดเชยต่อถัง
   - **ตารางสรุปรายบุคคล / เบอร์รถ**: รายชื่อผู้ขับ 340+ คัน พร้อมรหัส, เบอร์รถ, ทะเบียนรถ, สาขา, จำนวนวันวิ่งงาน, รวมระยะทาง, รวมน้ำมัน และยอดเงินชดเชยสุทธิ
   - **ส่งออก Excel (.xlsx)**: ดาวน์โหลดไฟล์ Excel พร้อมกันทั้ง 2 แผ่นงานในคลิกเดียว

3. **🏢 จัดการข้อมูลสาขาและพนักงาน (Branch & Vehicle Management)**
   - จัดการข้อมูลสาขาและผู้ประกอบการ 378 คัน
   - ระบบนำเข้า/ส่งออกเทมเพลต Excel สำหรับอัปเดตข้อมูลพนักงานชุดใหม่
   - ปรับแต่งราคาน้ำมันฐาน (Base Price: ค่าเริ่มต้น 30.00 บาท) และอัตราสิ้นเปลืองน้ำมันมาตรฐาน (11.0 กม./ลิตร)

4. **🔐 ระบบเข้าสู่ระบบด้วยรหัสพนักงาน (Staff Login)**
   - รองรับบัญชีพนักงาน 177 บัญชีจากแผ่นงานพนักงานต้นทาง
   - เข้าระบบด้วยรหัสพนักงาน พร้อมแสดงชื่อ-สกุล และสาขาที่สังกัด

## 🧮 กฎและสูตรการคำนวณ (Business Logic)

* **เกณฑ์ DIFF. + 10%**:
  * สถานะพิเศษ: `ไม่จด`, `NO`, `ลา`, `ไม่มีงาน`, `ไมล์เสีย` จะถูกคงสถานะไว้
  * หากผลต่าง $| \text{CRM} - \text{History} | \le 10\%$ ของค่า CRM $\rightarrow$ ยึดตัวเลข **History (GPS)**
  * หากผลต่างเกินกว่า $10\%$ $\rightarrow$ ตัดกลับไปใช้ตัวเลข **CRM**
* **สูตรเงินชดเชย**:
  $$\text{อัตราชดเชย (บาท/ลิตร)} = \max(0, \text{ราคาน้ำมันดีเซลประจำวัน} - 30.00)$$
  $$\text{ปริมาณน้ำมัน (ลิตร)} = \frac{\text{เลขไมล์สุทธิ (กม.)}}{11.0}$$
  $$\text{ยอดเงินชดเชย (บาท)} = \text{ปริมาณน้ำมัน (ลิตร)} \times \text{อัตราชดเชย (บาท/ลิตร)}$$

## 🚀 การติดตั้งและเริ่มใช้งาน (Getting Started)

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. รันแอปพลิเคชันสำหรับพัฒนา (Development Server)
```bash
npm run dev
```
เปิดเบราว์เซอร์ไปที่: **`http://localhost:3000/`**

### 3. ซิงค์ข้อมูลล่าสุดจาก Google Sheets (Live Data Sync)
```bash
npm run sync
```
คำสั่งนี้จะทำการดึงข้อมูลล่าสุดจาก Google Sheets ทั้ง 3 ไฟล์โดยอัตโนมัติ:
1. `sync_contractors.cjs`: อัปเดตรถผู้ประกอบการและบัญชีพนักงาน
2. `fetch_all_months.cjs`: ดึงแผ่นงานค่าชดเชยและเลขไมล์ Diff ทั้ง 8 เดือน
3. `build_full_multi_month_database.cjs`: ประมวลผลและสร้างฐานข้อมูล seedData.json

### 4. บิลด์สำหรับนำไปขึ้น Production (Build)
```bash
npm run build
```
